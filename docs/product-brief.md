# 제품 개요

## 프로젝트

공공체육관 예약 웹은 대학 캡스톤에서 기획했던 공공체육관 예약 앱
아이디어를 바탕으로 새로 구현하는 웹 프로젝트입니다.

## 포지셔닝

기존 캡스톤 프로젝트는 팀 프로젝트였고, 당시 담당 역할은 서비스 기획,
사용자 흐름 설계, 앱 전체 UI/UX 디자인이었습니다. 이 웹 버전은 개발자
포트폴리오를 위해 새로 구현하는 개인 프로젝트이며, 기존 Flutter 코드는
재사용하지 않습니다.

## MVP 목표

하나의 완성된 사용자 흐름을 먼저 구현합니다.

1. 공공체육관 목록을 확인한다.
2. 체육관 상세 정보를 본다.
3. 종목, 날짜, 시간을 선택한다.
4. 예약을 생성한다.
5. 내 예약과 QR 입장권을 확인한다.

## MVP에서 제외할 것

- 실제 결제 연동
- 관리자 대시보드
- 실서비스 수준의 SMS 본인인증
- 기존 모바일 앱 전체 기능 복제

## 포트폴리오 메시지

이 프로젝트는 기획과 디자인 경험을 실제 웹 서비스 구현으로 확장한
사례입니다. 도메인 모델링, 예약 플로우 설계, 프론트엔드 구현, 데이터
연동 과정을 보여주는 것을 목표로 합니다.
