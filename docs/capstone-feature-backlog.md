# 캡스톤 기능 확장 백로그

이 문서는 대학 캡스톤에서 기획했던 공공체육관 예약 앱 아이디어를 웹 MVP 이후
단계로 확장하기 위한 후보 목록입니다. 현재 프로젝트는 MVP와 1차 안정화, 계정/소셜
로그인, 관리자 기본 흐름, Postgres 운영 SSOT 전환을 마친 상태입니다.

## 진행 원칙

- 현재 흐름인 목록, 상세, 예약, 내 예약, 취소, 마이페이지, 관리자 기본 기능을
깨뜨리지 않습니다.
- 인증, 관리자, 실제 운영 데이터처럼 의존성이 큰 기능은 별도 단계로 분리합니다.
- 기능을 붙일 때마다 Prisma 모델, repository 경계, 화면 상태를 함께 갱신합니다.
- 실제 시설 예약처럼 보일 수 있는 문구는 피하고, MVP 성격을
명확히 유지합니다.

## 0단계 - MVP 마감

| 기능 | 상태 | 메모 |
| --- | --- | --- |
| 서울 공공체육시설 샘플 데이터 | 완료 | Postgres `gyms` seed와 mock JSON 기준을 맞춤 |
| 실제 예약 아님 안내 | 완료 | 전역 배너와 상세 화면에 표시 |
| 옛 체육관 예약 안전 표시 | 완료 | 현재 시설 목록에서 제외된 예약을 명시적으로 안내 |
| 최소 QA | 진행 중 | 자동 테스트는 통과. 브라우저 smoke test는 배포 안정화 후 재확인 |
| GitHub push | 보류 | 사용자 승인 후 진행 |

## 1단계 - 사용자 탐색 개선

| 기능 | 우선순위 | 의존성 | 메모 |
| --- | --- | --- | --- |
| 지도/위치 기반 탐색 | 중간 | 지도 API 결정 | 현재 위치 기반 거리 표시는 완료. 지도 UI는 별도 후보 |
| 즐겨찾기 | 완료 | 로그인 후 Postgres `favorites`, 비로그인 시연용은 localStorage |
| 최근 본 시설 | 중간 | 저장 위치 결정 | 예약 전 재방문 흐름 개선 |
| 필터 확장 | 중간 | 데이터 필드 확장 | 지역구, 종목 외 운영 요일, 가격, 시설 유형 |
| 시설 비교 | 낮음 | UI 추가 | 가격, 종목, 운영시간 비교 |

## 2단계 - 계정과 개인화

| 기능 | 우선순위 | 의존성 | 메모 |
| --- | --- | --- | --- |
| 이메일/비밀번호 로그인 | 완료 | Firebase Auth | soft email verification 정책 |
| Google 로그인 | 완료 | Firebase Auth | 일반 sign-in 흐름 |
| 카카오 로그인 | 완료 | Firebase custom token | handover ticket + nonce 검증 |
| 네이버 로그인 | 완료 | Firebase custom token | 카카오와 같은 handover 패턴 |
| 익명 로그인 제거 | 완료 | 인증 정책 | 익명 예약 이전 후보는 폐기. 모든 예약은 정식 계정 기준 |
| 마이페이지 | 완료 | `user_profiles` | 예약/즐겨찾기 요약, 프로필, 사진, 비밀번호, 탈퇴 |
| 알림 설정 | 낮음 | 알림 채널 결정 | 이메일, 캘린더, 브라우저 알림 후보 |

## 3단계 - 예약 현실성 강화

| 기능 | 우선순위 | 의존성 | 메모 |
| --- | --- | --- | --- |
| 시간대별 잔여 수량 | 완료 | `reservation_slots` | 정원/예약 수/마감 상태 관리 |
| 휴관일/운영시간 관리 | 중간 | 관리자 또는 seed 데이터 확장 | 시설별 세부 운영 정책은 추가 고도화 후보 |
| 예약 상세 화면 | 완료 | `/reservations/[reservationId]` | 예약번호별 상세, 취소 상태, 입장권 |
| 캘린더 저장 | 중간 | 클라이언트 기능 | 예약 이후 사용자 편의 기능 |
| QR 값 검증 흐름 | 낮음 | 관리자/현장 확인 화면 | 실제 입장권처럼 보이지 않도록 문구 주의 |

## 4단계 - 관리자 기능

| 기능 | 우선순위 | 의존성 | 메모 |
| --- | --- | --- | --- |
| 시설 관리 | 완료 | 관리자 권한 모델 | 이름, 주소, 좌표, 종목, 운영시간 관리 |
| 예약 관리 | 완료 | 관리자 권한 모델 | 사용자 예약 조회와 상태 변경 |
| 슬롯 관리 | 완료 | 관리자 권한 모델 | 날짜, 종목, 시간대별 정원/마감 관리 |
| 휴관일 관리 | 중간 | 시설별 일정 모델 | 예약 가능 시간 계산과 연결 |
| 공지 관리 | 낮음 | 데이터 모델 | 시설별 안내 문구 |
